# Theme Pillars - Working Direction

The theme remains deliberately loose.

## 1. The machine is the artifact
The pinball machine is a strange device capable of reaching impossible places. It is not merely a UI metaphor.

## 2. Accumulated wrongness
Every run visibly bolts incompatible discoveries onto the machine: occult artifacts, machinery, portals, biological oddities and other impossible components.

## 3. Realm-driven variety
Different biomes can have radically different visual identities while still feeling coherent because the machine is scavenging from those places.

## 4. Darkly playful, not grim
The world can be eerie, strange and occasionally grotesque without becoming joyless horror.

## 5. Minimal lore burden
Fiction exists to support gameplay and visual identity. Avoid lore that constrains mechanical experimentation.
