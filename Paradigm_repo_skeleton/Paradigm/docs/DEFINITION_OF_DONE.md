# Definition of Done

A ticket is done when:

- scope in the Jira ticket is implemented
- project launches without parser/runtime errors introduced by the change
- keyboard/controller behavior remains functional where relevant
- new authored content is data driven where appropriate
- obvious edge cases are handled
- debug-only behavior is gated from release behavior
- relevant docs are updated
- manual validation steps are recorded
- new follow-up problems are captured rather than hidden inside unrelated changes
